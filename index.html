EST 440 · Synthetic respondent experiment

Synthetic Consumer Panel

Does telling people an ad was made with AI change how much they trust it? Set up a panel of LLM-simulated consumers, show each one a single version of an ad, and compare the two conditions. Every persona is one independent call to the Claude API, and every request and raw answer is kept.

Respondents are simulated, not real consumers. Results show how the model represents these groups and should be checked against a small human sample.

01Setup

Claude API

The key is sent only to api.anthropic.com from this browser. Never commit it to GitHub.

Sample

Per cell: personas in each combination of age group, factor levels and condition. Parallel: API calls sent at once. Seed: fixes each persona's exact age and the run order, so the same settings give the same panel.

Persona factors

Levels: one per line as Label | text the persona sees. Untick a factor to leave it out of the design.

Background traits (random)

Each persona gets one option from every ticked trait, drawn at random with the seed. Traits make the people in a cell differ from each other, as real respondents do, without adding cells to the design. Options: one per line as Label | text the persona sees.

Stimulus

Claude sees the image itself. Video is not supported, so for a video ad use one key frame.

Prompt template

{profile} becomes the persona's lines, {ad} points to the image, which is sent before the text, plus the caption if there is one.
